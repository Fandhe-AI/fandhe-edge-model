## 4. 候補と学習

| 候補 | 学習の方法 | seed |
| ---- | ---------- | ---- |
| C1・C3 | 製品の CLI（`train --candidate 0/1 --train-seed S` → `select` → `evaluate`）を project3 の複製で行う。設定は既定（追補 2 と同じ扱い） | 0・1・2 |
| P15 | 格子 iters {300, 600} × lr {1e-4, 5e-5}・batch 4（追補 2 と同じ） | 0 で格子、代表構成で 1・2 |
| P7 | 格子 iters {600, 1,200} × lr {1e-4, 5e-5}・batch 2 | 0 で格子、代表構成で 1・2 |

- P7 の格子の変更: 学習データが 864 → 1,514 件に増え、iters を据え置くと 1 周に満たない（iters 300・batch 2 で約 0.4 周）。格子を「見せる例の数 {1,200, 2,400}」で定め直す
- P15 は batch 4 のため、iters を据え置いても見せる例の数は同じ {1,200, 2,400}（約 0.8・1.6 周）になる
- P7 の batch 2 は追補 2 の 5 節の短時間試行で決めた値をそのまま使い、試行はやり直さない
- 上記以外の学習・採点の設定、資源上限は追補 1・追補 2 と同じ

## 5. 選定と決定性

- P15・P7 とも、seed 0 の格子から、3 節の validation（164 件）で代表構成を選ぶ。選定規則は追補 2 の 3 節と同じ（validation 正解率 → Macro-F1 → iters が小さい方 → lr が小さい方）
- 選定に test_v3・val_v3 は使わない
- 決定性確認は P15 だけで行う（追補 2 の 9 節と同じ）。代表構成を seed 0 で再学習し、validation の予測ラベルを照合する
- seed 1・2 は代表構成のまま学習する

## 6. 採点の順序（1 回限り）

test_v3 への適用は 1 回限りとする（REQ-27）。次の順に進める。

1. 4 モデルすべてで「学習 → 選定 → seed 1・2 → val_v3 の予測」まで済ませる
2. test_v3 の予測（P15・P7）と `evaluate`（C1・C3）を行う
3. `fandhe-edge-score --project-dir project3` で、(候補名, seed) ごとに 1 回だけ採点する

- test_v3 の結果を見て構成・設定を選び直さない
- C1・C3 の val_v3 の予測は、製品が使った学習リクエストと学習データをそのまま使い、学習ワーカーを直接呼んで得る。元の validation の予測が製品の結果と全件一致することで、同じモデルと確かめる

## 7. 主な結果と有意性

- 主: test_v3 の正解率と Wilson 95% 区間。3 seed の各値と平均を出す
- 従: 追補 2 の 8 節と同じく、seed ごとに McNemar の正確検定（両側）と Holm 補正を行う。判定の基準は追補 2 の 8 節のまま変えないが、主な結果としては扱わない

## 8. 層別（事前に固定）

- test_v3 を、test 専用の値を含む場面（162）と含まない場面（162）に分け、それぞれの正解率を出す
- 区分は `test_v3.meta.jsonl` の `novel` 属性で決める。`screen`・`purpose`・`both` を「含む」、`null` を「含まない」とする
- 層別は採点済みの予測ファイルから別に集計する。モデルへの再適用ではない
- 予測ファイルと採点 JSON の sha256 を併記する

## 9. 旧データとの比較

- 旧データのモデルは test_v3 で採点できない。採点の道具が評価記録を凍結 test と定義に束縛し、名前も固定のため
- 旧 → 新の比較は val_v3 で示す

| 学習データ | 正解率（val_v3） |
| ---------- | ---------------- |
| 旧（864 件） | 53.6% |
| v3（972 場面） | 91.8% |

- 条件: C3、学習ワーカー直呼び・40 エポック・5 seed
- 旧 test（project2）と test_v3 は別の test として扱い、並べない

## 10. 気をつける点・証拠の種別

- val_v3 は学習データの 3 段目を足す判断（学習曲線）に使ったため、完全には無垢でない。凍結 test の代わりにはならない
- 証拠の種別は実機とする。Apple M5・低電力モードはオフ。P15・P7 は GPU bf16、C1・C3 は CPU

## 11. 所要（推定）

- 全体で 10 時間超
